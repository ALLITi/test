# Snake Game

A simple browser-based Snake game. Steer the snake with the arrow keys or WASD, eat food to grow, and avoid hitting the walls or yourself.

## Getting started

1. Open `index.html` in your browser directly, or serve the directory with a simple server (for example, `python -m http.server 8000`).
2. Use the on-screen Restart button or press the space bar to start a new game. Your highest score is saved locally so you can keep improving between sessions.

### Do I need to re-download?

No. Clone the repository once and keep the local copy. When changes are pushed, simply run `git pull` in the project directory to fetch the latest files instead of downloading everything again.

## Controls

- Arrow keys or **WASD** to change direction
- **Space** to restart when the game is over
